Objetivo: Desenvolver uma página web estática de portfólio pessoal, inspirada no modelo do portfólio do professor, praticando estrutura HTML semântica, estilização com CSS e hospedagem de imagens via GitHub.

Instruções gerais:
Vocês irão criar uma página de portfólio semelhante à do professor, mas com conteúdo pessoal (foto, nome, habilidades, projetos e contatos seus). A página deve manter a estrutura principal do exemplo (header com foto + nome + bio, seções de Habilidades, Projetos e Contato), mas vocês têm liberdade para alterar cores, fontes, tamanhos, espaçamentos, bordas, efeitos, disposição dos elementos etc., desde que:

    Não mudem drasticamente a organização em seções
    Continuem utilizando HTML5 semântico e CSS puro (sem frameworks como Bootstrap)
    A página fique visualmente agradável e legível

Requisitos obrigatórios:
Repositório de imagens no GitHub 

    Crie um repositório público separado só para imagens (sugestão de
    nome: seuusuario-imagens ou portfolio-imagens).
    Dentro dele, crie uma pasta (exemplo: Portfolio, fotos, projetos)
    e suba as imagens que você vai usar.


Imagens 

    Escolha e use suas próprias imagens (ou imagens livres de direitos):Uma imagem (para o header) ,  pelo menos 3 imagens representando seus projetos (capturas de tela ou ilustrações)


As imagens devem ficar hospedadas no repositório de imagens que você criou.

No código HTML, insira as imagens usando links diretos/raw do GitHub.
