# Programação Front-End 🌐

Este repositório contém os projetos, exercícios e estudos desenvolvidos durante a disciplina de **Programação Front-End** do curso técnico em **Desenvolvimento de Sistemas (Subsequente)**, seguindo as diretrizes da Nova Matriz Curricular 2025.

## 📖 Sobre a Disciplina
A unidade curricular foca na capacitação para o desenvolvimento de interfaces de usuário que sejam eficientes, atraentes e funcionais. O objetivo é interpretar requisitos de design e transformá-los em aplicações web modernas, utilizando as tecnologias fundamentais da Web.

*   **Carga Horária:** 100 horas-relógio (120 horas-aula).
*   **Semestre:** 2º Semestre.

## 🛠️ Tecnologias e Conhecimentos
De acordo com o plano de curso, os estudos abrangem:
*   **HTML (HyperText Markup Language):** Estruturação de conteúdo e arquitetura de elementos.
*   **CSS (Cascading Style Sheets):** Estilização, design visual e uso de extensões.
*   **JavaScript & TypeScript:** Implementação de comportamentos dinâmicos através de linguagens de script.
*   **Consumo de APIs:** Integração e comunicação com o back-end.
*   **Ferramentas e Frameworks:** Uso de tecnologias de *Visual Web* para otimização do desenvolvimento.

## 🎯 Competências e Habilidades Desenvolvidas
Ao longo deste repositório, são aplicadas as seguintes competências previstas:
- **Interpretação de Briefings:** Identificação de requisitos técnicos e funcionais para projetos de websites.
- **Prototipagem:** Desenvolvimento de habilidades de design visual e estruturação de interfaces.
- **Organização de Projetos:** Pesquisa de domínios, serviços de hospedagem e gestão de arquivos por etapas.
- **Codificação:** Criação de rotinas utilizando linguagens específicas e manutenção de registros para refinamento de resultados.
