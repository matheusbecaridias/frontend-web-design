1. Criar o arquivo HTML

    Abrir o editor de texto e criar um arquivo chamado index.html.
    Inserir a estrutura básica do HTML5.
    Adicionar os seguintes elementos:
    Título da página (ex: "Minha Página Pessoal")
    Um cabeçalho com o nome completo
    Uma imagem (pode ser uma foto pessoal ou uma imagem da internet)
    Um parágrafo com uma breve descrição ou apresentação pessoal
    Uma lista com pelo menos três hobbies ou interesses
    Um rodapé com informações de contato (email ou redes sociais)

2. Criar o arquivo CSS

    Criar um arquivo chamado styles.css na mesma pasta do HTML.
    Vincular o arquivo CSS ao HTML usando a tag <link> dentro do <head>.
    Aplicar estilos básicos, como:
    Cor de fundo da página
    Cor e fonte do texto
    Espaçamento entre os elementos
    Estilização da lista (tipo de marcador, cor)
    Estilização da imagem (bordas arredondadas, tamanho)

3. Testar e ajustar

    Abrir o arquivo index.html no navegador para visualizar a página.
    Fazer ajustes no código HTML e CSS conforme necessário para melhorar a aparência e organização.
